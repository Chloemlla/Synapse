# GeoGebra 工作台：用户指南

> 适用对象：使用 `/geogebra` 的普通用户（本地画布对游客开放，云端能力需要登录）。

## 这是什么

一个把 GeoGebra 画布和脚本编辑器放进 Synapse 的数学工作台：写脚本、跑画布、保存项目、
和团队一起审阅、把画布公开分享出去。所有云端数据都保存在你自己的账号下。

## 本地工作台

- 画布类型：平面几何、立体几何、函数图形、综合工作台。切换类型前如果有未保存的拖动调整，会先确认。
- 脚本编辑器支持行号、折叠、括号匹配与中文注释，`Ctrl/Cmd + Enter` 直接运行。
- 运行前会做基本检查（括号、行格式、明显不安全的内容），并在有高风险指令时给出提醒。
  **这些检查只是提前发现明显问题，不代表脚本一定安全**——请只运行你自己写得清来源的脚本。
- 运行后会给出逐条结果：哪一行成功、哪一行失败、各用了多久，以及整体成功率。
  长脚本运行期间可以点「停止运行」，会在当前指令结束后停下，不会被当成脚本报错。
- 画布上拖动自由点后，面板会列出「脚本里的原指令 → 保存后的指令」，你可以只保留选中的点。
  如果同时又改了脚本，会先弹出确认再覆盖。
- 导出：PNG、SVG、GGB、脚本文本（`.ggs.txt`）。演示模式下也能导出 PNG / SVG / GGB。
- 编辑器与画布并排显示，桌面端滚动时画布会保持在视野内；下方按「项目与版本 / 协作与分享 /
  参数与样式 / AI 与导出 / 讲解与记录」分区，不用在一条很长的页面里来回滚动。

## 参数、样式与课堂讲解

- 参数调节：脚本里形如 `a = 2`、`flag = true`、`title = "…"` 这样的简单赋值会被识别成参数，
  可以「应用参数」或「应用并运行」。
- 画布样式：可对全部对象或所选对象设置颜色、线宽、点大小、标签、网格与坐标轴；
  个别对象不支持该设置时，会告诉你具体是哪几个没生效。
- 课堂讲解：把脚本逐条重放，支持上一步/下一步/自动播放/停止。
- 演示模式：隐藏编辑界面，只留画布与运行/导出/退出。

## 云端项目与版本（需要登录）

- 保存到云端后，可以在任意设备打开；默认**关闭**每 5 分钟自动保存，需要时打开即可。
- 云端已有更新版本时，页面不会静默覆盖：会摊开两边差异，让你选择
  「打开云端版本」或「用本机版本覆盖云端」。
- 云端历史版本可以看与当前脚本的差异，并一键应用（应用前会确认，因为它会替换当前脚本）。

## 团队与评论

- 可以把项目放进团队空间；团队角色有管理员、编辑者、审阅者、查看者。
- 邀请成员需要邮箱；成员列表里可以调整角色或移除成员。
  创建者不可被移除，团队至少保留一名管理员。
- 评论可以关联到某个版本或某个画布对象，并标记为已解决。

## 分享与复用

- 发布公开分享会得到分享地址与嵌入地址，持有链接的人可以查看这份画布；
  你也可以随时撤销（撤销前会确认，撤销后链接与嵌入地址立即失效）。
- 嵌入地址打开的是只读画布，画布准备好后会自动运行一次；没有运行画布时也可以发布，
  只是分享页不会带预览图。
- 别人公开分享的画布可以「fork」到你自己的项目里继续改。

## AI 辅助

- 能力：按描述（可附一张参考图）生成构造脚本、解读当前脚本、给出对象标注建议、解释对象依赖。
- 参考图只用于这一次生成，任务结束即删除；只能在明确支持图片的配置下使用。
- **AI 结果只是建议**：页面会先给你看摘要、指令与把握度，你可以逐条勾选要写回的指令，
  再点「替换脚本」或「追加到脚本」；写回编辑器时仍会再过一遍预检，预检不通过就不会写回，也不会执行。
- 解释对象依赖时，除了 AI 的文字说明，还会给出本地推导的依赖关系（谁依赖谁、在第几行），
  断网或 AI 不可用时同样可以查看。
- 使用 AI 需要先同意使用政策与服务专项条款。

## 导出与打包

- 画布侧：PNG、SVG、GGB、脚本文本；这些在「AI 与导出」和编辑器工具栏里都能直接下载。
- 服务端打包：把项目脚本与版本打包成 ZIP，稍后在页面上下载（有有效期）。
- PDF / GIF / MP4 / PPTX 目前**由画布侧或浏览器打印完成**，服务端不具备渲染/编码能力；
  页面会如实标注可用范围，不会给出点了必然失败的按钮。

## 隐私要点

- 本地项目保存在当前浏览器里；云端项目、版本、评论与分享保存在你的账号下。
- 云端项目按你的账号隔离；团队项目按团队成员角色授权。
- 删除云端项目会同时移除其版本与评论，并撤销关联的公开分享。
- 撤销或删除分享后，原公开地址立即失效。
