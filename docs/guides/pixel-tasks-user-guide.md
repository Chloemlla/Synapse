# Pixel 自助折扣链接：用户指南

> 适用对象：使用 `/pixel` 页面的普通用户。
> 本文只讲「怎么用、会看到什么、需要注意什么」，不涉及内部实现。

## 这是什么

用一张卡密提交一批账号，由外部折扣链接服务完成「提取折扣链接」与可选的「绑卡」，
处理结果以任务形式返回，你可以随时查看进度、导出结果、取消仍在排队的账号。

## 开始前必须知道

- 提交时会把账号的**邮箱、密码、辅助邮箱、2FA 秘钥**交给外部折扣链接服务处理。
  这些内容只在这次提交时使用，不会保存在 Synapse。
- 只能提交**你本人**或**已获授权管理**的账号。
- 首次进入会弹出操作提示，勾选确认后才可提交；勾选「今天不再弹出」只影响浏览器上的提示频率，
  正式授权仍以你同意的服务条款与服务专项条款为准。

## 使用步骤

1. **登录**：页面要求登录，任务与额度都绑定在你的账号上。
2. **验证卡密**：输入卡密后点「验证卡密」（也可以直接按回车）。页面上会显示：
   - 剩余额度（展示值）；
   - 计费单位额度（用于估算与对账，和展示值量纲不同，两者不要混看）；
   - 卡密状态：可用 / 不可用。即使显示不可用，只要还能查到历史任务，页面会给出「查看历史任务」入口。
3. **选择服务类型**：
   - 仅提取链接（预估 0.5 额度/账号）
   - 提取链接 + 绑卡（预估 1）
   - 提取链接 + 绑卡（1 美元方案，预估 1.5）
   被后台关闭的类型不可选；若你之前选过、后台又关掉了，页面会自动回退到「仅提取链接」并提示。
   **页面显示的是预估额度，实际扣额以服务端与上游返回为准**（已有链接时扣额可能不同）。
4. **粘贴账号**：每行一个账号，格式为

   ```
   邮箱----密码----辅助邮箱----2FA密钥
   ```

   页面会实时显示已填账号数与预估最高额度；少于 2 段或多于 6 段、含控制字符、单行过长都会被拒绝，
   错误会指名第几行。
5. **提交任务**：提交后页面给出任务号并开始显示进度。

## 任务与结果

- 任务状态：排队中 / 处理中 / 已完成 / 未完成 / 已取消。
- 每个账号的状态：排队中、处理中、已成功、待绑卡、绑卡中、绑卡成功、绑卡未成功、未成功、已取消。
  排队中的账号会显示排队位次。
- 处理中时页面每 5 秒自动刷新一次，进入终态后停止。
- 有结果链接的账号会在该行显示「查看结果链接」。

## 导出

- **单个任务**：任务有可导出账号时，任务区出现「导出结果」，得到纯文本文件，
  每行 `email----result_link`。
- **按卡密全部**：历史区有「导出全部结果」，把该卡密下你已完成的账号一起导出。
- **我的任务数据**：页面顶部「导出我的任务数据」会给你一份 JSON，
  只包含任务归属与脱敏后的调用记录（不含账号原文、密码、2FA 秘钥）。

## 取消排队

只有仍在**排队中**的账号能取消；取消后该账号不会再被处理，额度按服务端规则回补。
已经开始处理的账号不能取消——按钮不会出现，强行请求也会被拒绝。

## 结果不确定时怎么办

如果提交时网络中断或上游异常，页面会提示「结果不确定」：

- **不要**立刻重复提交，否则可能重复扣额；
- 到「历史任务」里按卡密确认这次提交是否已经成功；
- 确认确实没有提交成功后，修改一下账号内容（哪怕加一个空格再删掉即可）再提交。

## 常见状态说明

| 现象 | 含义与下一步 |
|---|---|
| 提示「需要先同意相关条款」 | 页面里的同意门禁未完成，按提示打开并勾选后再操作 |
| 提示「操作过于频繁」 | 触发了限流，等待一会儿再试；提交类操作每分钟额度更低 |
| 提示「该服务当前不可用」 | 上游未配置或被管理员关闭；这是服务端统一拒绝，与你的账号无关 |
| 卡密不可用但能看到历史 | 该卡密不能再开新任务，但历史任务仍可查询与导出 |

## 撤回与删除

- 卡密与账号内容不会留在浏览器；离开页面即从内存清除。
- 需要删除任务归属与调用记录时，按平台账号注销流程处理；注销后这些记录立即不可访问。
- 如果只是想让某个账号停止处理，用「取消排队」。
