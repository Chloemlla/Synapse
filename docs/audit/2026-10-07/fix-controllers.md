Cross-group contracts implemented here:

- `GET /api/admin/shortlinks`: authenticated cookie requests receive `{ success, items, total, page, pageSize }` and `Cache-Control: no-store`; explicit Bearer requests retain the existing AES-256-CBC `{success,data,iv}` format.
