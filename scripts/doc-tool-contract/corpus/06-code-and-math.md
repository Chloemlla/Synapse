# 代码与公式混排

这一份专门用来防止 C4（公式完整）误判：代码块里出现的 `$$`、`$`、`\[` **不是公式**。

## 一段含有假公式的代码

```js
// 这个 $$ 在代码块里，不该被算成公式
const price = 12; // 美元符号 $12 也不是公式
const tex = "\\[ x^2 \\]";
```

行内代码也一样：`$$a+b$$` 与 `$5.00` 都不是公式。

## 真正的公式

行间公式一：

$$
F = G\frac{m_1 m_2}{r^2}
$$

行间公式二：

$$
\nabla \cdot \mathbf{E} = \frac{\rho}{\varepsilon_0}
$$

行间公式三：

$$
\Delta x \Delta p \geq \frac{\hbar}{2}
$$

行内公式：当 $v \ll c$ 时，$\gamma \approx 1$。

## 结论

源 Markdown 里的公式计数必须跳过围栏代码与行内代码，否则「产物 3 个公式 / 源 9 个公式」会
得出「丢了 6 个公式」的错误结论 —— 一个永远修不好的假缺陷比没有缺陷更消耗信任。
