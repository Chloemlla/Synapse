# 一级标题

这一段是正常的一级标题下的正文，用来观察 C7（标题不跳级）在只有一级标题时的表现。

### 三级标题（故意跳级）

从一级直接跳到三级，是学生写实验报告时最常见的结构错误：中间那一层往往被当成「不需要写」。

##### 五级标题（再跳一级）

再跳一次。检查项 C7 会把这两处跳级都数出来，并给出「只能人工改源 Markdown」的结论 ——
结构问题不应该由后处理器去猜（猜错就是把学生的章节顺序改了）。
