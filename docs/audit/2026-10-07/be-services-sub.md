## 3. 存疑 / 需人工确认

1. **`src/services/turnstile/ipBan.ts:isIpBanned` 的 fail-open 语义**：Mongo 断开时返回 `{banned:false}`，与「Redis 缺失时安全降级」的仓规一致，但这意味着 DB 故障期间恶意 IP 可绕过封禁。是否要把「DB 不可用时人机验证整体 fail-closed」作为独立开关，需要产品/安全负责人定夺。
2. **`src/config/lumen.ts:44` `outemailApiUrl` 与 `outemailBaseUrl` 默认指向 `chloemlla.com`**：若 Project Lumen 被第三方部署且未显式配置，邮件验证码会发到运营方域名。属「默认配置是否应带作者域名」的运维策略问题。
3. **`src/services/lumen/config.service.ts:getConfigSync`** 的 `templates` 用 `AdminTemplate.find({ updatedAt: { $gt: requestedCursor } })`，而 `requestedCursor` 来自客户端 query；若客户端传一个很大的值，模板会被静默过滤为空。下游是「配置同步」语义，可能是有意为之（增量拉取），未确认客户端契约。
4. **`src/services/userGenerationStorage/`** 当前生产代码无调用方（`rg -ln "userGenerationStorage" src --glob '!tests/**'` 仅命中测试）。上述 sub-10/11/12 的严重度因此按「潜在缺陷」而非「线上活跃」评估；若该模块计划重新启用，需先修。
