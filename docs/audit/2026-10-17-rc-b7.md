### RC-14：IDC 出口的升档与 API Key 降速

**改动文件**

- `src/utils/accountRiskScoring.ts`
  - `resolveIdcEscalationAction(tier, autoEscalationCap)`：纯映射
    `normal → mark_watch`；`watch/restricted` 且 `cap=restricted → restrict`；其余 `null`；
    `danger` 永远 `null`。
- `src/services/accountRiskService.ts`
  - `handleIdcEgressRisk({userId, ipAddress, ipRisk?, source})`：本判据的**唯一落点**。
    - 开关：`accountRisk.enabled && accountRisk.ipRecheckEnabled`（默认关）；关闭时零副作用。
    - 频率：同账户 5 分钟内只处理一次（有界 Map）。
    - 只读缓存（`getCachedIpRisk`），不外呼。
    - 命中：写 `ACCOUNT_ABUSE_IDC_EGRESS` → `resolveIdcEscalationAction` →
      `applyAccountRiskAction`（RC-07 唯一处罚出口）。
    - `restrict` 的副作用：step-up 窗口续期 + 该账户**全部 API Key 降速**
      （`setApiKeyPenalty`，`source=account-risk:restricted`）。
      （API Key 三态与 `apiKeyAuth` 的状态分派已由 RC-19 落地，本批未改 `apiKeyModel`。）
    - superadmin：`isRiskExempt` + `SUPERADMIN_RISK_EXEMPT` 留痕，不升档。
- `src/middleware/accountStepUpGuard.ts`
  - 已登录写请求的 5 分钟复查里加入 IDC 判定（复用已读到的缓存结论）；
    IDC 升档对**所有档位**生效（否则 `normal → watch` 永远发生不了），
    但中/高风险的挑战/封禁仍只对 `watch` 及以上生效。
- `src/middleware/apiKeyAuth.ts`
  - 鉴权成功后 fire-and-forget 触发 `handleIdcEgressRisk`（`source: "api_key"`）。
  - 依赖用 `require` / `import()` 延迟加载，避免把整套模型拖进 `apiKeyPenalty.test.ts`；
    配置不可读时按「观察期关闭」处理。

**验证点**

- `auditB7.test.ts` → `RC-14 handleIdcEgressRisk`：
  - 开关关闭：不查缓存、不写事件、不写用户；
  - 非 IDC：不写；
  - `normal + IDC`：`riskTier=watch`、写 `ACCOUNT_ABUSE_IDC_EGRESS`、写审计；
  - `watch + IDC + cap=restricted`：`setApiKeyPenalty(throttled)`；
  - `danger`：不升档、不降速；
  - superadmin：留痕不升档；
  - 5 分钟频率闸。
- CI 上 `apiKeyPenalty.test.ts` / `stepUp.test.ts` / `accountRiskAction.test.ts` 应保持绿
  （未改这些套件依赖的出口语义）。

**偏离与解释**

- 审计原文 RC-14.3 写「`restricted` 及以上出现 IDC 出口时**直接升档**」。本批**不**把
  `restricted → danger` 自动化（§3：danger 必须人工），也不 `suspend`；`restricted` 账户的
  「升档」表现为 `restrict` 的续期 + API Key 降速。`danger` 账户只留信号（`cap-reached`）。
- 「API Key 立即吊销」在本批走的是 RC-19.4 既有联动：`applyAccountRiskAction("restrict")`
  降速、`("suspend")` 暂停全部 Key；IDC 判据本身不会触发 `suspend`。
- 网页端复查只覆盖**写方法**（闸门挂在写请求上）。GET/SSE/WS 的复查需要挪到
  `authenticateToken`（不在本批可编辑清单），见 §4 接线清单。
